# Movie Shot Analyzer — Camera Calibration Solver v1.1

Camera Calibration Solver v1 の精度計算には触れず、右パネルのUIだけを修正した版です。

## UI修正
- パース・レンズ右パネルの横スクロールを完全に無効化
- 縦スクロールのみ使用
- 右パネル幅を 350–430px の範囲に調整
- X / Z / Y の3ボタンを同じ幅でパネル内に収める
- 軸ボタンのみ少し小さいフォントにして日本語表記を全部見せる
- リセットボタン、長い結果表示もパネル幅に追従

## FIX仕様
- 左右パネル開閉を維持
- パースタブ上部に説明文を置かない
- X軸（水平・左右方向）
- Z軸（奥行き方向）
- Y軸（垂直・上下方向）
- 自動判定データ・自動解析・自動学習データは使用しない

## 計算
Camera Calibration Solver v1 のカメラSolve、レンズ推定、Solve errorの計算ロジックは変更していません。
