# Movie Shot Analyzer V5.22

- VP1–VP2を結ぶ実際の幾何学的な地平線は、別の細い破線 **VP HORIZON** として分離
- パース/レンズ計算は従来通り実VP座標を使用（水平表示は計算を改変しません）
- VP1–VP2から Camera Roll（°）を表示

- 出力は元画像解像度のPNG。表示中の構図ガイド、パース線、EYE LEVEL、VP HORIZON、緑フレーム、表示補正を反映
- 白い編集ハンドル等の操作UIは書き出しに含めない
- 元画像は上書きせず `_guides.png` で保存
- V5.21までの手動パース、学習、人物/局所線抑制、A/B/C、←→、F、左右パネル等を維持
