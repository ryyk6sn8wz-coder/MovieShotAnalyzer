# Movie Shot Analyzer V5.38 — Camera Solver

「パース・レンズ」タブをカメラキャリブレーション中心に整理した段階移行版です。

- 構図ガイドは別タブのまま
- X / Z / Y(up) の基準線を従来の鉛筆式2ストロークで入力
- 安定していた手動入力/state machineは維持
- X/Zの直交VPから焦点距離px、35mm換算、水平/垂直FOVを計算
- Y(up)が有限VPならカメラ整合性検証に利用
- 直交カメラ残差から Solve error (°) を表示
- カメラ解グリッド、軸別表示、EYE LEVEL / VP HORIZONを維持
- 自動パース解析はUIから切り離したまま
- 手動学習データ保存を維持
- 書き出しにカメラ解グリッド・基準線・レンズ/カメラ情報を含められる
- レンズ/カメラ情報は画像上方中央、小さめ横一列、透明度/文字サイズ設定対応

V5.38では既存の手動操作を壊さないことを優先しています。水平・垂直方向が実質無限遠VPになるケースの完全な同時最適化は次段階です。
