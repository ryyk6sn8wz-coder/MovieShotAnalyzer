# Movie Shot Analyzer V4 Analyzer 2

Windows動作確認済みのV4 Base / Analyzer 1を土台に、補助線操作とガイド表示を改善した版です。

## 主な変更
- 「追加 縦線/横線」のスピンボックスを廃止し、＋縦 / ＋横ボタンに変更
- ＋自由線を追加。斜めを含む任意方向の補助線を作成可能
- 自由線の両端○をドラッグして角度調整
- 自由線そのものをドラッグして平行移動
- 選択した補助線の削除 / 全削除
- ガイド線の太さ 1〜10 px
- ガイド線の透明度
- 交点に塗りつぶし○を表示
- ○サイズ、外周太さ、塗り色、外周色、透明度を調整
- 三分割の固定線は従来どおり動かない
- 黒帯検出、4辺フレーム調整、表示補正を維持

## 次段階
この版のWindows動作を確認後、VP1〜3、画像外VP、アイレベル、自動VP候補、35mm換算レンズ推定を追加します。
