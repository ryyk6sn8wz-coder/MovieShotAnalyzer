# Movie Shot Analyzer V6.0.1 — Reset & Ray Fix

## 修正
- 選択軸リセット後の再入力を完全な空状態から開始。
- リセット前の既定線/ハンドルが再入力を邪魔しないよう修正。
- VP3リセット時は古い infinity 状態もクリア。
- 放射線マスターONなら、再入力完了時にその軸の放射線表示を確実に復帰。
- X/Z/Yをリセットして引き直しても表示状態がずれにくいよう同期。
- Yが無限遠の場合は「放射状」ではなく平行ガイドになることをUIで明記。
- 左右パネルの折りたたみは維持。

## ZIP/EXE
`build_exe.bat` を `--onefile` に変更。
Windowsローカルビルドは `dist/MovieShotAnalyzer.exe` 1ファイルになります。
余分な onedir フォルダを作りません。
