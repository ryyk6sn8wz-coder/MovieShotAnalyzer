# Movie Shot Analyzer V5.30

## 手動パースを「正常に動いていたV5.11」へ戻しました
今回はV5.26〜V5.29の手動パース修正を継ぎ足していません。
V5.11の以下の実装を現在版へ直接戻しています。

- `_perspective_hit`
- `mousePressEvent`
- `mouseMoveEvent`
- `mouseReleaseEvent`

これにより、V5.11当時の鉛筆式2本線入力・1本目の表示・2本目の確定・白丸微調整のイベント処理へ戻しています。

### 現在版から残したもの
- 手動確定データの学習保存
- 自動解析
- レンズ推定
- VP3∞判定
- 水平EYE LEVEL
- 黒帯自動フレーム
- 全画像フレーム適用
- 非ブロッキング一括書き出し
- 進捗・キャンセル
- 現在のUI

### 短い線
V5.11のイベント処理はそのまま使い、線の最小長判定だけ `0.015` から `0.0005` に下げています。
奥の机・窓枠などの短いエッジも確定対象です。

### 学習データ
手動で2本目を確定した後だけ `learn_current_perspective('manual')` を呼びます。
自動判定や学習処理は、手動のマウス入力状態には介入しません。
