# Movie Shot Analyzer V5.28

## 手動パース：短い基準線対応
- 奥の机、窓枠、棚などの短いエッジでも基準線として確定できます。
- 旧版の `0.015` 正規化長さ閾値を廃止しました。
- 約1px以上ドラッグしていれば有効な基準線として扱います。
- 完全なクリックだけ（ほぼ0px）は誤操作として無視します。
- 1本目・2本目とも同じ判定です。
- 2本目を離したら、その線の長さに関係なくVP段階を確定します。
- VP1確定 → VP2へ自動移行、VP2確定 → VP3へ自動移行。
- 各段階で鉛筆ドラッグ状態を完全リセットしてから次のVPへ進みます。
- VP3のほぼ平行判定（∞扱い）、自動フレーム、一括書き出し、EYE LEVEL仕様は維持しています。
