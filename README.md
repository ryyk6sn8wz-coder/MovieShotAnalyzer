# Movie Shot Analyzer — Perspective Core Test 2

V5.30 の安定していた鉛筆式2ストローク入力をそのまま土台にして、
パース計算だけを修正した確認版です。

## 今回の修正
- VP1 / VP2 の計算で消失点を [-6..7] / [-5..6] に強制クランプしていた処理を廃止。
  遠い消失点でも、ユーザーが引いた2本の基準線の本来の交点を保持します。
- 遠いVPでも放射線が画像まで届くよう、描画半径をVP距離に応じて自動拡張。
- VP3(Y/垂直)は、弱い収束の縦線を無理に有限VPへしない。
- VP3が∞の場合は、ユーザーが引いた2本の縦基準線から平均方向を作り、平行ガイドを表示。
- 平均方向が画面垂直から2°以内だけ、手ブレとして完全垂直へスナップ。
- Camera Solver / 後期版のY補正は使用しません。
- UI・レンズ等は今回のテスト対象外です。

まず教室カットで X→Z→Y の順に2本ずつ引き、
放射線/平行ガイドが実際の窓・机・柱に沿うか確認してください。
