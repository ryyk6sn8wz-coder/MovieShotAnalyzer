# Movie Shot Analyzer — Pure Manual Perspective v1

パース計算を完全な手動入力だけに限定した切り分け版です。

## パース計算に入るもの
- その画像でユーザーが今引いた X / VP1 の2本
- その画像でユーザーが今引いた Z / VP2 の2本
- その画像でユーザーが今引いた Y / VP3 の2本

## 完全に除外
- 自動パース解析
- A/B/C候補
- 自動検出線
- 過去の自動解析結果
- 自動判定用学習データ
- perspective_learning.json の読み込み
- 学習データによる補正

## VP3
- ほぼ平行、または「縦として認識できる2本で弱い収束」の場合は Y=∞
- Y=∞では有限VP3を作らず、手動2本線の平均方向の平行ガイドを表示
- ほぼ画面垂直なら小さな手ブレだけ垂直へスナップ
- 明確に収束する場合だけ有限VP3を使用
