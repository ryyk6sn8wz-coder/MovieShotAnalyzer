# Movie Shot Analyzer V4 Analyzer 3

Windows UI確認済みの V4 Base / Analyzer 2 系統を土台にした構図分析版です。

## Analyzer 3 の主な変更
- 実映像フレームを四隅で自由変形可能
- 緑のフレーム各辺もドラッグ移動可能（傾き・台形に対応）
- ガイド線の太さを 0.5 px 刻みで調整
- 交点○サイズを 0.5 px 刻みで調整
- 交点○外周線を 0.5 px 刻みで調整
- 数値操作を「− / 数値 / ＋」方式に変更
- ガイド線の透明度 0% = 完全透明
- 交点○の透明度 0% = 完全透明
- 線と交点○の透明度を独立調整

## 継続機能
- 画像 / フォルダのドラッグ＆ドロップ
- 三分割固定線
- 中央十字、黄金比、黄金螺旋、対角線、三角構図、対称軸
- 縦 / 横 / 自由補助線
- 自由線の両端ハンドルと平行移動
- 黒帯自動検出
- 明るさ / コントラスト / ガンマ / 彩度（表示のみ）
- モノクロ画像対応

この版で操作系を確認後、VP・アイレベル・35mm換算レンズ推定を追加する予定です。
