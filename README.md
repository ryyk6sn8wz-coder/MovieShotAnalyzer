# Movie Shot Analyzer V5.2.1 — Movable Composition Guides

Windows / macOS (Apple Silicon) 共通ソースの構図分析ツールです。

## V5.2.1: 追加構図ガイドを直接編集
V5.1で追加した構図ガイドを、キャンバス上で直接調整できるようにしました。

1. 使いたい追加構図ガイドをON
2. 「追加ガイドを編集（クリックで選択）」をON
3. ガイド線をクリック
4. 選択中のガイドだけ白い○ハンドルを表示
5. ○をドラッグして形を変更 / ガイド線をドラッグして全体移動
6. 編集をOFFにすると○は完全に消え、ガイド線だけ表示

### 可動ガイド
- 放射構図：放射中心を移動
- トンネル / フレームインフレーム：内側4隅を自由変形。線ドラッグで全体移動
- ゴールデントライアングル：各端点を調整
- 円構図：中心 / 横半径 / 縦半径
- C字構図：中心 / 横半径 / 縦半径
- V字構図：左右端と頂点
- ダブル対角線：4端点
- S字構図：ベジェ曲線の制御点
- L字構図：3点
- ピラミッド構図：頂点と底辺2点

「選択中ガイドを初期位置へ戻す」で、そのガイドだけ初期形状に戻せます。

## 固定・既存ガイド
- 三分割（固定）
- 中央十字
- 黄金比
- 黄金螺旋
- 対角線
- 三角構図
- 対称軸

Balance / Unbalanced のように被写体の視覚重量を見ないと判定できないものは、固定ガイドにはせず、後の画像解析による「構図タイプ判定」に回す設計です。

## 維持している機能
- Photoshop風の実映像フレーム自由変形
- 黒帯自動検出
- 補助線（縦 / 横 / 自由線）
- ガイド線太さ 0.5刻み
- 交点は外周なしの塗りつぶし円
- ガイド / ポイント / フレーム透明度 0% で完全非表示
- 明るさ / コントラスト / ガンマ / 彩度（表示のみ）
- 画像 / フォルダのドラッグ&ドロップ
- Windows / macOS Apple Silicon 共通ソース

## Windows
`build_exe.bat` または GitHub Actions + PyInstaller でビルドできます。

## macOS Apple Silicon
`build_macos.sh` を用意しています。M4 Maxを含むApple Siliconを対象にしています。


## V5.2.1 修正
- 「追加ガイドを編集」を初期状態でONに変更しました。
- 追加ガイドをクリックすると選択され、選択中のガイドだけ○ハンドルが表示されます。
- 線を押したままドラッグで全体移動、○ドラッグで形状調整できます。
- 何もない場所をクリックすると選択解除され、○が消えます。
