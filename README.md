# Movie Shot Analyzer V5.26

## 手動パース修正
- 1本目を確定した後、2本目を描いている間は1本目を完全固定します。
- 2本目のドラッグ中はVPをリアルタイム再計算しません。
- 2本目を離した時点で初めてVPを計算します。
- マウスを離したら描画ドラッグ状態と鉛筆カーソル状態を解除します。
- 白丸ハンドルによる後からの微調整は維持します。
- V5.25の自動フレーム、非ブロッキング書き出し、進捗、キャンセル、EYE LEVEL条件表示は維持します。

# Movie Shot Analyzer V5.25

## 主な変更
- 画像を初めて読み込んだ時、黒帯を自動検出して緑フレームへ適用（デフォルトON）。
- 各画像ごとに検出するため、上下黒帯・左右黒帯・黒帯なしに対応。
- 「このフレームを全画像に適用」を追加。手動調整した1枚を全画像へ統一可能。
- 一括書き出しを非ブロッキング化。1枚ごとのQt描画の間にイベントループへ制御を返すため、従来のように全処理中UIが固まり続けません。
- PNG圧縮・ディスク保存は複数ワーカースレッドで並列化。
- 進捗表示とキャンセルボタンを追加。
- 完了ダイアログを広げ、長い保存先を別行表示。
- EYE LEVELはVP1＋VP2確定後だけ表示するV5.24仕様を維持。
- 書き出しクラッシュ対策を維持。

### 安全性
Qt Canvasの描画自体はGUIスレッドに残しています。QWidget/QPainterをワーカースレッドから直接操作するとWindowsで強制終了する危険があるためです。
PNG保存だけを並列化し、UIを固めない方式にしています。
