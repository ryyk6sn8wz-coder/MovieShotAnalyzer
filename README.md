# Movie Shot Analyzer V5.29

## 手動パース入力を独立ステートマシンへ置換
VP1-1本目 → VP1-2本目 → VP2-1本目 → VP2-2本目 → VP3-1本目 → VP3-2本目 → 完了

- Press → Drag → Release で必ず1本を終了。
- Release時はVP計算より先にマウスとの接続を解除。
- 確定済み線は次のマウス移動から完全に切り離されます。
- 約1px以上の短い線も有効。奥の机・窓枠・棚などに使用可能。
- Release取りこぼし時も左ボタンUP検出で強制確定。
- 新規鉛筆入力中は白丸ハンドル編集が入力を横取りしません。
- VP1確定後はVP2、VP2確定後はVP3へ自動進行。
- 自動解析、レンズ、VP3∞判定、フレーム、一括書き出し、EYE LEVELは変更していません。
