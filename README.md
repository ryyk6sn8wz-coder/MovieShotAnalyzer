# Movie Shot Analyzer V5.32

V5.31を基準に、VP3だけを追加修正しました。VP1/VP2のV5.11手動入力には触れていません。

## VP3が∞（垂直線ほぼ平行）の場合
- VP3の有限マーカーは出しません。
- ただしガイドは消さず、2本の手動基準線の平均方向から「平行ガイド」を生成します。
- VP3線数（2〜48）、色、太さ、透明度、ON/OFFをそのまま使用します。
- 画像内パースグリッドONなら、緑フレーム内にも同じ平行ガイドを表示します。
- つまり垂直に近いカットでも縦方向のガイドを利用できます。

## VP3 2本目の確定
- VP3だけ専用の確定処理を追加。
- 約1px以上ドラッグすれば短い線でも確定。
- Release時に先にカーソルとの接続を解除します。
- Windows/QtがmouseReleaseを取りこぼした場合も、左ボタンが離れているのを検出するとVP3を確定します。
- 手動学習データ保存は維持します。

## 変更していないもの
- VP1/VP2のV5.11手動パース入力
- レンズ推定
- EYE LEVEL / VP HORIZON
- 自動解析
- フレーム
- 一括書き出し
