# Movie Shot Analyzer V5.24

## V5.24 変更点
- EYE LEVELは初期状態では表示しません。
- VP1だけ確定してもEYE LEVELは表示しません。
- VP1＋VP2が両方確定した時点で、黄色の水平EYE LEVELを表示します。
- VP HORIZONもVP1＋VP2確定後だけ表示します。
- パースをリセットするとEYE LEVEL / VP HORIZONも消えます。
- 自動解析でも、有効なVP1＋VP2が成立した場合だけ表示します。
- V5.23の書き出しクラッシュ対策は維持します。
- 一括書き出し、手動パース、A/B/C候補、学習、←/→、F表示など既存機能を維持します。

# Movie Shot Analyzer V5.23

## V5.23
- Windowsで「現在の画像を書き出し」「全画像を一括書き出し」を押した際に強制終了する問題を修正
- 原因になり得る「非表示の一時QWidgetを生成してrender()する」方式を廃止
- 実際に表示中のCanvasを安全にgrabし、画像領域だけを切り出して元画像サイズへ書き出す方式へ変更
- 編集ハンドルは書き出さない
- EYE LEVELは黄色の完全水平線
- VP1-VP2の幾何学Horizonは灰色の細い破線「VP HORIZON」にして見分けやすくした
- 現在画像/全画像一括の両方を維持

# Movie Shot Analyzer V5.22

## V5.22
- 黄色の **EYE LEVELを必ず画面水平** に描画するよう修正
- VP1–VP2を結ぶ実際の幾何学的な地平線は、別の細い破線 **VP HORIZON** として分離
- パース/レンズ計算は従来通り実VP座標を使用（水平表示は計算を改変しません）
- VP1–VP2から Camera Roll（°）を表示
- **現在の画像を書き出し** を追加
- **全画像を一括書き出し** を復活
- 出力は元画像解像度のPNG。表示中の構図ガイド、パース線、EYE LEVEL、VP HORIZON、緑フレーム、表示補正を反映
- 白い編集ハンドル等の操作UIは書き出しに含めない
- 元画像は上書きせず `_guides.png` で保存
- V5.21までの手動パース、学習、人物/局所線抑制、A/B/C、←→、F、左右パネル等を維持
