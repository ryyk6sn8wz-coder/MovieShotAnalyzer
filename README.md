# Movie Shot Analyzer V6.0 — Camera Calibration Solver

参考サイト型のカメラキャリブレーションUIへ移行する版です。

## パース・レンズ
- X軸（水平・左右方向）
- Y軸（垂直・上下方向）
- Z軸（奥行き方向）
- 既存の安定した鉛筆式2本入力を維持
- 手動基準線を観測データとしてカメラ/レンズを推定
- 35mm換算焦点距離、HFOV/VFOV、Solve error、Confidenceを表示
- 平面グリッドを主表示にする
- 放射線は補助表示として残す
  - 初期状態OFF
  - X/Y/Zを個別ON/OFF可能
  - 本数調整可能
- 軸の基準線、消失点マーカーも個別表示切替
- EYE LEVEL / VP HORIZONは維持
- 自動パース解析は引き続きUIから切り離し
- 手動学習データ保存は維持
- レンズ/カメラ情報は画像上方中央、小さめ横一列で書き出し可能
- 左右サイドパネルの折りたたみ操作は維持

## 方針
V6.0では「グリッド主体・放射線は診断用」という構成へ移行しています。
既存の手動VP入力を壊さないことを優先しつつ、Camera Calibration Solverへ段階的に置き換えています。
