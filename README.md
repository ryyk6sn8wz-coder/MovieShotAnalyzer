# Movie Shot Analyzer — Camera Calibration Solver v1

参考サイト型の「1台のカメラを解く」方式へパース計算を作り直した試作版です。

## 入力
- X軸（水平・左右方向）: 手動2本
- Z軸（奥行き方向）: 手動2本
- Y軸（垂直・上下方向）: 手動2本
- 自動判定データは一切使用しません。

## 計算
1. 各2本の線を画像上の観測として扱う
2. 各軸の消失方向を同次座標で求める（無限遠も自然に保持）
3. 2軸以上で共通カメラをSolve
4. 3軸揃った場合は主点(cx,cy)と焦点距離fを、3方向が最も直交するよう数値最適化
5. X/Y/Zを最近傍の直交3軸へフィット
6. 同じカメラから一貫したX/Y/Z消失点・無限遠方向を再投影
7. そのカメラ解から35mm換算、HFOV/VFOV、Solve errorを表示

## FIX仕様

- パースタブ上部に説明文を置かない
- 表記固定:
  - X軸（水平・左右方向）
  - Z軸（奥行き方向）
  - Y軸（垂直・上下方向）
- 自動判定/自動解析/自動学習データはパース計算に入れない
