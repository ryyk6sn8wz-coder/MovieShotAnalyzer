# Movie Shot Analyzer V5.27

## V5.27
- 手動パースを VP1 → VP2 → VP3 の自動進行へ復旧。
- VP1の2本目を離して確定すると、自動でVP2の1本目待ちへ移行。
- VP2確定後は自動でVP3へ移行。
- 次のVPへ移る際、古い/default基準線を完全に消してから開始するため、白丸が鉛筆操作を横取りしにくくしました。
- 各VPは「1本目 → 2本目 → mouseReleaseで確定」の状態遷移を維持。
- VP3の2本がほぼ平行（角度差2.5°未満）の場合、無理な有限VPを作らず `VP3: ∞（垂直線ほぼ平行）` と扱います。
- VP3が無限遠扱いのときは、誤解を招くVP3マーカー/放射線を表示しません。
- 自動解析側の「垂直線がほぼ平行ならVP3を無限遠扱い」も維持。
- V5.25以降の黒帯自動フレーム、全画像へのフレーム適用、非ブロッキング一括書き出し、進捗/キャンセルを維持。
- EYE LEVELはVP1+VP2成立後のみ水平表示。
