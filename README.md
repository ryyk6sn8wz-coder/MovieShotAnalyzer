# Movie Shot Analyzer V5.37 — Manual Study UI

## 今回の方針
自動パース判定をUI/実行導線から一旦外し、手動分析を安定させる版です。
自動解析の実装コードは将来の再実装用にソース内へ残していますが、UIからは呼び出しません。

## UI
右タブ順:
1. 構図ガイド
2. パース・レンズ
3. ショット分析

構図ガイド内:
- 基本ガイド
- 構図考察ガイド
- 補助線
- ガイドの見た目

左右パネルの折りたたみボタンと F の画像優先表示は従来どおり残しています。

## パース
- VP1 / VP2 / VP3 は手動入力
- 3軸パースグリッド
- EYE LEVEL / VP HORIZON
- レンズ推定
- 手動・修正パースの学習データ保存は継続
- 自動解析ボタン、検出線、A/B/C候補はUIから撤去

## 書き出し
- 構図ガイド
- 手動パース基準線
- 3軸パースグリッド
- VP / EYE LEVEL / VP HORIZON
- 緑フレーム
を現在の色・線幅・透明度で焼き込みます。

レンズ情報は画像上方中央へ小さな横一列:
`Lens 32mm eq. | FOV 59.0° | Range 28–35mm | Confidence High`

- レンズ情報 ON/OFF
- 小さめフォント（初期 11px）
- フォントサイズ変更
- レンズ情報透明度変更
- 現在画像/一括書き出しの両方で同じ表示
