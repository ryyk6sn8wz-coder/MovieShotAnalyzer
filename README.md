# Movie Shot Analyzer V5.31

V5.30の正常化した手動パース入力には触れず、VP3が∞判定された場合の表示だけ修正しました。

- VP3∞では有限VP3マーカーを表示しない
- VP3∞ではVP3放射線・画像内VP3グリッドを表示しない（既存条件を維持）
- VP3入力に使った2本の緑の実線は残す
- その2本を画面外まで延長する長い破線は表示しない
- 白丸ハンドルは残し、手動微調整可能
- 表示を「VP3 完了：∞（垂直線ほぼ平行）・白○で微調整」に変更
- 手動学習データ保存は維持
- VP1/VP2、EYE LEVEL、レンズ、自動解析、フレーム、書き出しは変更なし
