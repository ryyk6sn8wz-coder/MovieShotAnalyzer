# Movie Shot Analyzer V5.34

V5.33を基準に、VP3が手動で引いた角度から勝手に垂直へ寄る問題を修正しました。

- VP3の平行判定を正規化座標ではなく画像の実ピクセル比率で計算します。
- VP3∞判定の許容角を 2.5° から 0.6° に厳しくしました。
- わずかでも実際の収束がある場合は有限VP3として扱い、平行ガイドへ丸めません。
- 本当に平行なVP3∞の場合も、ユーザーが引いた2本の角度を長さ加重平均して、その傾きを平行ガイドへ反映します。
- したがってカメラロールなどで垂直線群が斜めになっていても、画面垂直へ自動補正しません。
- VP1/VP2のV5.11由来入力、VP3確定処理、学習保存、EYE LEVEL、レンズ、自動解析、フレーム、書き出しは変更していません。
