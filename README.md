# Movie Shot Analyzer V5.39 — VP3 Solver

V5.38 Camera Solverをベースに、Y軸（VP3/垂直）の扱いを重点修正した版です。

## 変更点
- 軸ラベルを明示
  - X（水平方向）
  - Y（垂直・上下方向）
  - Z（奥行き方向）
- Y軸の2本の基準線がほぼ平行なら `Y = ∞`
- Y = ∞ のとき、手描き2本の平均方向をそのまま採用せず、X/Zから解いたカメラ姿勢に整合する垂直方向を使用
- Y軸が明確に収束するときだけ有限VP3として採用
- Y軸のユーザー入力と理論Y方向の角度差をSolve errorへ加算
- ステータス欄に `Y: ∞（平行・カメラ垂直）` または `Y: 有限VP` を明示
- 既存の安定した鉛筆式2本入力、X/Z計算、レンズ推定、学習データ保存は維持
- 自動パース解析は引き続きUIから切り離し

## 注意
Yの∞判定しきい値は現状 2.25°。実際のカットで必要なら調整します。
