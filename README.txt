Movie Shot Analyzer
====================

Windows 11向け。映画キャプチャを一括分析します。

できること:
- 三分割、黄金比、黄金螺旋、三角構図、対角線、中央、対称ガイド
- OpenCVによる直線検出から1点/2点透視の「候補」を推定
- 消失点を画像に表示
- 推定アイレベル
- 直交する消失点が十分に取れた場合の35mm換算焦点距離の目安と水平画角
- 全画像を一括処理
- analysis.csvを出力

重要:
レンズ値と消失点は画像からの推定値です。映画素材ではクロップ、デジタルズーム、
手ブレ補正、非直交な線、複雑な背景などで誤推定します。
特に「水平な線」を自動検出して消失点を求める方式には限界があります。

最も確実な使い方:
1. まず構図ガイドを一括生成
2. パースは候補として見る
3. 必要なカットだけ、消失点を手動指定する機能を追加する

Python版:
  movie_shot_analyzer.py

自動EXE化:
  build_exe.bat
をダブルクリック。dist\MovieShotAnalyzer.exe ができます。
